## 通用规则
1. 在本机完整 clone `nevermeetagain/product-development-skill`，主线模式：每卡一提交，直推 main，禁止建分支、force push、rebase。
2. 每卡开工前读 plan.md 对应卡的“执行步”和“验收”；开工前一行自评（需求/依赖/测试路径：高/中/低）。
3. 每卡只跑 `node scripts/self-test.mjs` 中与本卡相关的用例，加本卡新增用例；不跑其他回归。每阶段结束跑一次完整 self-test。
4. 偏离卡面写一行裁决（决定—理由—若错的代价），写进提交信息，然后继续。只有不可逆、安全、外部副作用、计划根本错误才停下问。
5. 同一卡失败两次停手，写出两次修复共同依赖的前提，回报 Hark。
6. 不写入任何秘密；pd.mjs 保持零依赖、Node 18+、Windows 与 Ubuntu 同命令。
7. 提交信息：`feat(PDS-6xx): <一句话>`，正文写“为什么 / 改了什么 / 怎么验证（命令 + 通过数）”。
